# Connect Four

Это веб-приложение для игры в «Четыре в ряд» — но идея была не просто реализовать классику, а сделать из неё небольшой игровой продукт с мультиплеером и заделом на развитие.


## Что получилось

Основной фокус был на онлайн-режиме: чтобы позвать друга в игру можно было за пару кликов, без регистрации на его стороне, без лишних шагов. Просто создать комнату, передать код — и играть. Именно это оказалось самой трудоёмкой частью: реализовать WebSocket-соединение с нормальной синхронизацией ходов, автопереподключением и управлением состоянием комнаты.

Игровая механика полная: проверка победы по горизонтали, вертикали и обеим диагоналям, физика падения фишек, hover-превью хода. Есть локальный режим — два игрока на одном устройстве. Авторизация через Supabase: регистрация, логин, сохранение сессии, базовый профиль.

Интерфейс сделан минималистичный, с поддержкой тёмной темы.

Архитектурно всё разделено: игровая логика, сетевой слой и UI существуют независимо.

## Что не успел

Большая часть времени ушла именно на онлайн-часть, поэтому за бортом остались история матчей, таблица лидеров и AI-противник.


## Если думать дальше
Но интересно порассуждать, куда можно было бы двигаться, если бы это был настоящий сервис.

Для удержания интереса хотелось бы добавить puzzle-режим — позиции, в которых нужно найти выигрышный ход — и какую-то прогрессию: рейтинг, история партий, возможно эксперименты с форматами вроде скрытой части поля или таймера на ход.

С точки зрения монетизации классика жанра — скины и косметика, premium-режимы, аналитика партий. Ничего особенного, но для небольшой игры вполне рабочая модель.
